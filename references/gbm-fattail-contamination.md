# GBM 分位数反常：肥尾污染 μσ 窗口（2026-07-17 实测）

## 背景

用户问"159599 下周走势"。对 159599 做 GBM 5 日（下周 5 个交易日）分位数预测，**同时算了 7 日窗和 20 日窗**的 μσ。

## 数据

159599（芯片ETF东财）：
- 今日（2026-07-17）收盘 2.928，**-7.31%** 大阴线
- 5日 -21.40%，20日 -12.91%，60日 +28.14%
- RSI(14)=25.9（严重超卖）

## GBM 分位数对比

```
S0 = 2.928, T = 5个交易日

7日窗:  μ=-2.999%  σ=6.206%
  q16=2.174   q50=2.496   q84=2.180   ← ⚠️ q84 < q50，反常！

20日窗: μ=-0.691%  σ=5.068%
  q16=2.511   q50=2.811   q84=2.517   ← 正常排列
```

## 机制分析

1. **7 日窗 μ 被肥尾污染**：单日 -7.31% 把 7 日平均日漂移拉到 -3%/天（约年化 -750%），完全不可信。
2. **σ 也膨胀**：7 日 σ=6.2% 远大于 20 日 σ=5.07%。
3. **GBM 公式里 σ²·t 主导**：5 日扩散项 σ·√t ≈ 6.2%·√5 ≈ 13.9%，而漂移项 |μ·t| ≈ 3%·5 = 15%，但 (μ - 0.5σ²) 的方差修正把净漂移拉到负值，分位数塌缩。
4. **结果反常**：q84 < q50 在概率上不可能（84 分位必须 > 50 分位）。这是数值 artifact，不是真实预测。

## 铁律

| 情况 | 动作 |
|------|------|
| |单日涨跌| > 5% 时算 GBM | 必须同时报 7 日窗 + 20 日窗，以 20 日窗为主结论 |
| q84 < q50 或 q50 < q16 | 断言失败 → 标注"μ 被肥尾污染，分位数反常"，不报该窗结论 |
| 输出 | 两套数字都展示，让用户看到漂移被污染的证据 |

## 159599 实例输出模板

```
=== 下周(5个交易日)GBM价位区间 ===
7日窗(⚠️今日-7.31%已污染漂移): 16%=2.17  50%=2.50  84%=2.18(反常)
20日窗(主结论):                 16%=2.51  50%=2.81  84%=2.52
→ 以20日窗为准：中位2.81，区间2.51~2.81
```
