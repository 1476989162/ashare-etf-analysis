# 浙商积存金买点分析 (2026-07-10 实战固化)

用户问"积存金(浙商/民生金价)买点,3天不被套"时,**不要**用黄金ETF净值×100 代理,直接读用户项目数据库拿**真实浙商金价历史**。

## 数据源 (权威, 用户项目 G:\goldServer)
- 真实金价在 `G:\goldServer\data\gold.db` 的 `jd_gold_price` 表(`Name='浙商金价'` 行, 7万+条记录, 每日多次抓取)。
- 云端 `http://43.240.223.64:47998/api/gold/jcj-live` 返回 **401**(需认证); 京东 `btfront.jd.com` 金价页是 **JS 渲染**, 直接 HTTP 拿不到 JSON。
- **正确姿势: sqlite3 直连本地文件**, 别撞云/京东。
```python
import sqlite3
con = sqlite3.connect(r'G:\goldServer\data\gold.db')
cur = con.cursor()
cur.execute("SELECT LastPrice, CapturedAt FROM jd_gold_price WHERE Name='浙商金价' ORDER BY rowid")
rows = cur.fetchall()
```
- 取每日末值做日线, 算对数收益率 → `mu`(日漂移), `sigma`(日波动)。实测 σ≈1.27%/日, μ≈-0.21%/日, 年化~20%。近20日区间约 874.5~935.7 元/克。

## 站岗概率定义修正 (关键坑)
用户要"3天不被套/不站岗", 站岗必须定义为 **"以买点 L 为起点, T日后收盘价仍 < L(没回本)"**, **不是从现价 G0 算**:
```python
# ❌ 错: 从现价算 L*(1-delta) 的触达 -> 高波动下恒100%, 无意义
p_trap = p_hit_lower(G0, L*(1-delta), mu, sigma, T)
# ✅ 对: 以买点L为起点, T日后收盘<L 的概率 = 1 - cdf(-mu*T/(sigma*sqrt(T)))
sT = sigma*math.sqrt(T)
p_trap = (1 - _cdf(-mu*T/sT)) * 100   # 只取决于 mu/sigma, 与L无关
```
### 数学事实 (必须向用户说清)
- 黄金微跌趋势(μ<0)下, **任意买点后3日未回本概率恒≈39%**, 压低买点降不了它(站岗只取决于 μ/σ)。
- **拉长持有到7天, 站岗率降到~33%**; 再长更低。
- 所以"3天不站岗"统计上做不到<35%, 但 **"3天大概率买到(成交95%+) + 持有1周大概率回本"可以兼得** —— 这是诚实的甜点。
