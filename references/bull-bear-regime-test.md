# 牛熊判定 + 缩量验证方法论（2026-07-13 实战）

用户问"是不是已经熊市了""今天大A整体缩量"这类**市场 regime 判定**问题，必须**用客观数据判定**，不能凭盘面感觉或用户叙事下结论。

## 1. 牛熊客观定义

- **熊市** = 主要指数从 250 日高点回撤 **≥ 20%** 且进入下行趋势（60 日动量持续为负）。
- **牛市后回调/震荡** = 回撤 5%~20%、年线仍正 → 不是熊市。
- 单日大跌 ≠ 熊市；缩量阴跌 ≠ 熊市。看**回撤幅度 + 趋势方向**双因子。

## 2. 数据拉取（腾讯 API，全量不靠感觉）

```python
import json, urllib.request
idx=[('sh000001','上证指数'),('sz399001','深证成指'),('sh000300','沪深300'),('sh399006','创业板指')]
for code,name in idx:
    d=json.loads(urllib.request.urlopen(f'https://web.ifzq.gtimg.cn/appstock/app/kline/kline?param={code},day,,,250',timeout=15).read().decode())
    k=d['data'][code]['day']
    closes=[float(x[2]) for x in k]
    cur=closes[-1]; hi=max(closes)
    dd=(cur/hi-1)*100
    yoy=(cur/closes[0]-1)*100
    m60=(cur/closes[-61]-1)*100 if len(closes)>61 else 0
    m20=(cur/closes[-21]-1)*100
    print(f'{name} 现{cur:.0f} | 距250日高回撤{dd:.1f}% | 250日{yoy:+.1f}% | 60日{m60:+.1f}% | 20日{m20:+.1f}%')
```
⚠️ 创业板 `web.ifzq.gtimg.cn` 端点偶发返回 0 根（空），回退到 `qt.gtimg.cn` 实时行情 + 已知近期高点估算，或换 proxy 端点重试。

## 3. 缩量验证（别信"今天缩量"的盘面感觉）

- 拉上证指数**近 15 日成交量日 K**，对比今日**盘中累计** vs 历史日均。
- ⚠️ **盘中时点只占全天约 70% 时段**（如 13:48 离收盘还 1h12m），需把盘中累计 ÷ 已交易时段占比外推到全天，再和历史日均比，才能定性"缩量/平量/放量"。
- 若用户说"今天缩量"，先出数据再附和，不要直接当事实。

## 4. 判读档位

| 距250日高回撤 | 年线(yoy) | 60日动量 | 判定 |
|---|---|---|---|
| <10% | 正 | 小负 | 牛市后回调/震荡（非熊市） |
| 10%~20% | 任意 | 转负 | 深度回调，警惕转折 |
| ≥20% | 任意 | 持续负 | 确认熊市 |

## 5. 实战（2026-07-13 盘中，腾讯API）

| 指数 | 距高回撤 | 250日 | 60日 | 20日 |
|---|---|---|---|---|
| 上证 | −7.3% | +13.8% | −2.3% | −2.4% |
| 深证 | −10.4% | +40.0% | +0.2% | −2.0% |
| 沪深300 | −6.6% | +19.8% | +0.5% | −1.1% |
| 创业板 | ~−5.7% | — | — | −2.1% |

**结论：非熊市，是涨一年后的缩量回调（回撤 5%~10%），60 日动量仅小负。** 不应用"熊市"叙事驱动清仓；策略本就不赌 A 股方向，守住"不接飞刀、不追跨境高溢价"即可。

## 6. 对用户的回答原则

- 给客观数字 + 判定档位，再给"对你操作的含义"（你的策略不依赖 A 股牛熊，维持低溢价+轻仓+境外防守）。
- 区分"制度性劣势"（A股让散户吃亏）与"杀猪盘"（非全市场骗局）——准确说法是结构性劣势，不是每个标的都是骗局。资金外逃海外 + QDII 高溢价（513310 +15%、161226 +8.8%）是真实需求溢出，非操纵。
