# 反弹概率筛选（量化方法）

当用户问"X天内反弹Y、概率≥Z%"这类**量化筛选**问题时使用本方法。区别于普通买卖点位分析——这里是批量扫描、用历史波动率算概率。

## 触发场景
- "15天内反弹0.3以上，概率80%以上的基金"
- "0.1或0.3以上，概率70%以上，15天内，多分析几只"
- 任何"找能涨X、概率Y%"的候选筛选需求

## ⚠️ 必问澄清：元 vs %
用户说"反弹0.3"时**必须先澄清**是 0.3% 还是 0.3元，両者结果天差地别：
- **0.3%**：所有基金统一涨幅，多数能达
- **0.3元（绝对价位）**：低价基金几乎不可能。例：159865现价0.53，0.3元=+56.6%；563000现价1.135，0.3元=+26.4%。这些15天内概率≈0%

本次会话实测：用户选了**0.3元绝对价位**，8只持仓中无一只达80%（最接近518880黄金盘中59%）。

## 方法（对数正态模型）
数据：腾讯K线 `web.ifzq.gtimg.cn/appstock/app/fqkline/get?param={sym},day,,,120,qfq`（前复权，120日）。

1. 日对数收益率 `r_i = ln(close_i / close_{i-1})`
2. 均值 `mu`、标准差 `sigma`（日）
3. **收盘达目标概率**（N日）：`P = 1 - Φ((need - mu*N) / (sigma*sqrt(N)))`，其中 `need = 目标涨幅/现价`
4. **盘中触及目标概率**（N日，更实用）：用日最高价相对昨收的对数收益 `hr_i = ln(high_i / close_{i-1})`
   - `hmu, hsig` = hr的均值/标准差
   - 单日触及 `z = (need - hmu)/hsig`，`p_day = Φ(z)`
   - N日内任意一天触及：`p_any = 1 - p_day^N`
   - **盘中口径概率远高于收盘口径**（黄金0.1元：收盘39% vs 盘中99.9%）

## 关键结论（2026-07-08实测，22只ETF扫描）
- **0.1元反弹、盘中概率≥70%**：黄金系5只(518880/518660/518850/518800/159830)盘中99.9% + 161226白银96% + 513520日经75.6% + 513310中韩半导体100%
- **0.3元反弹、收盘口径≥70%**：**无一只**
- **0.3元反弹、盘中口径≥70%**：**仅513310中韩半导体（99.8%）**真正达标（日漂移+0.58%、日波动4.2%，弹性最强）
- 黄金系特点：盘中必摸0.1（波动大）但收盘站稳仅39%（趋势仍弱，日漂移-0.09%）

## ⚠️ 用户偏好：扫描不限持仓
用户明确"不要只限于持仓，你自己找一下"。**主动选20-30只流动性好的T+0/高波动ETF**（黄金系+跨境系+部分高波动行业），不要只分析SQL持仓。优先T+0（用户风险偏好）。

## 输出格式
给两张表（按概率排序）：
1. 达标清单（概率≥阈值），区分收盘/盘中两种口径
2. 若严格收盘口径无达标，明确说"无"，并给盘中口径最接近者

## 验证纪律
script算完用 ad-hoc 复算最高概率样本（如513310、518880）确认数字一致，断言概率∈[0,1]、盘中≥收盘。详见 `scripts/rebound_scan.py`。

## 数据时效性
- K线用120日历史，实时价用 `qt.gtimg.cn` 快照（开盘后拉，9:14前是昨收）
- 模型是历史波动率正态近似，**非价格预测**，仅作概率参考
- 跨境ETF(513500等)注意溢价率：溢价>3%提示不过夜，>5%建议清仓
